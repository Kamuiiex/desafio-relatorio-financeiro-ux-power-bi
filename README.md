# Atualizando Relatório Financeiro com Foco na Experiência do Usuário

Projeto desenvolvido durante a Formação Power BI Analyst da DIO, com foco na melhoria da experiência do usuário em um relatório financeiro no Power BI.

## Objetivo

O objetivo do desafio foi aprimorar um relatório já existente, aplicando conceitos de experiência do usuário, organização visual e navegabilidade.

Foram considerados aspectos como:

- Posicionamento dos elementos
- Contraste
- Organização visual
- Segmentação dos dados
- Navegação entre páginas
- Destaque da página selecionada
- Melhor aproveitamento dos visuais
- Criação de uma matriz para detalhamento das vendas

## Estrutura do relatório

O relatório final possui 3 páginas:

### Home
Página inicial do relatório, com botão de acesso à análise e menu de navegação.

### Visão Geral
Página com os principais indicadores e análises:

- Total de Vendas
- Unidades Vendidas
- Lucro Total
- Descontos
- COGS
- Vendas por Período
- Vendas por Segmento
- Vendas por Produto
- Análise geográfica de vendas

Também foram mantidos recursos interativos para alternar alguns tipos de visual.

### Detalhamento
Página destinada à exploração mais detalhada dos dados, contendo:

- Indicadores principais
- Vendas por Período
- Matriz de Detalhamento de Vendas
- Hierarquia por País, Segmento e Produto
- Vendas
- Lucro
- Unidades Vendidas
- Descontos

## Melhorias de experiência do usuário

Entre as principais melhorias realizadas estão:

- Criação de menu de navegação em todas as páginas
- Destaque automático da página ativa
- Botão de navegação na página inicial
- Padronização dos indicadores
- Melhor organização dos elementos
- Redução de elementos redundantes
- Criação de uma página específica para detalhamento
- Uso de hierarquia expansível na matriz
- Manutenção de filtros de período para exploração dos dados

## Ferramenta utilizada

- Microsoft Power BI Desktop
